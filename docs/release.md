# Выпуск и проверка Friday Desktop

## Канал обновлений

Для workflow **Signed Windows release candidate** нужны отдельные GitHub Environments `friday-beta` и `friday-stable`. Для каждого задайте переменные `FRIDAY_UPDATE_ENDPOINT` (HTTPS URL файла `latest.json`), `FRIDAY_UPDATER_PUBLIC_KEY` (публичный ключ Tauri Updater) и `FRIDAY_RELEASE_ASSET_BASE` (HTTPS-каталог артефактов этой версии без имени файла).

Секреты окружения включают `FRIDAY_SIGNING_PFX` (PFX в Base64), `FRIDAY_SIGNING_PFX_PASSWORD`, `TAURI_SIGNING_PRIVATE_KEY` и, при необходимости, `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`. Сборка проверяет Authenticode у установщика и у приложения внутри него, проверяет наличие подписи updater и готовит манифест, lockfiles, SBOM и SHA-256. Для проверки приложения при локальной сборке понадобится 7-Zip. Публикация установщика и манифеста происходит после проверки кандидата. Сначала размещается установщик по указанному URL, затем обновляется манифест.

Изменение ключа updater требует переходного выпуска с новым публичным ключом, доставленного через прежний доверенный канал. При неудачном релизе остановите раздачу манифеста. Исправление выпускается с новой версией, совместимой с сохранённым профилем. Старый клиент откажется записывать профиль, если его схема новее поддерживаемой.

## Проверка кандидата на Windows

- Установить чистый кандидат, открыть окно и проверить трей, повторный запуск и выход. Выполнить составную локальную команду с отключённой сетью. Сверить громкость с системой и статус запуска с окном приложения.
- Подключить встроенный микрофон, USB- и Bluetooth-гарнитуру. Проверить начало записи, окончание, отмену, отключение устройства, блокировку Windows и сон во время записи, STT и озвучки. После разблокировки запись должна начинаться только по новому действию пользователя.
- Проверить настройки и команды с помощью клавиатуры и Narrator. Проверить масштабы 100%, 150% и 200%, конфликт горячей клавиши и недоступный голос Windows.
- С тестовым ключом Groq проверить русскую и английскую речь, диалог, запрос инструмента и отказ при снятом разрешении. Проверить ошибку авторизации и недоступность сервиса.
- Поставить предыдущий подписанный кандидат. Создать историю и настройку горячей клавиши, установить обновление, проверить данные и подписи. При тестах повреждённого пакета, отсутствующей подписи и попытки downgrade процесс установки должен отклонить пакет.

## Локальные данные и диагностика

Профиль находится в каталоге данных текущего пользователя, который создаёт Tauri для `io.github.n1dlee.friday-desktop`. Диагностику можно просмотреть и экспортировать из настроек. Журналы JSON ограничены по размеру и содержат коды ошибок, идентификаторы ходов и результаты действий. Аудио, переписка и ключи в журналы не включаются.

Если запись зависла после отмены, Friday сохраняет владение ресурсом до завершения очистки. При необходимости завершите работу через меню трея и откройте приложение заново. Если операция в Windows могла выполниться до сбоя, проверьте её результат вручную перед повтором команды. Friday отмечает такие операции в локальном журнале квитанций.

Критерии готовности стабильного выпуска включают аппаратный прогон, подпись, обновление и замеры бюджетов на поддерживаемой Windows. Проверки браузерного интерфейса используют тестовый IPC и дополняют этот прогон.
